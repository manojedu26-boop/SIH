# Investigator Portal Validation

The public homepage remains login-free by default. The header action and the investigator tab open a restricted portal overlay explicitly labeled as a prototype. The entry screen communicates invite-only provisioning, official email domains, MFA, scoped access, audit logging, and the sensitive-data warning without pretending that real authentication is connected.

The post-login preview exposes a Bengaluru South district-reviewer scope, session metadata, new/under-review/resolved summary counts, high-risk notification, jurisdiction map texture, searchable and filterable prioritized queue, score cards, reason strings, review action, and mobile Queue / Map / Search / Exit navigation. The mobile view uses compact typography and thumb-reachable controls; the desktop view uses a split queue/map layout.
